# Linux / macOS

Что нужно для запуска

ЧастьТребования
Установщик и переносная версия (Windows)Windows 10/11, Python не нужен, права администратора не нужны
Linux / macOS (бинарник)Ничего; для окна в Linux обычно есть Tk, значок в трее — pystray
Чистый Python (.pyz, исходники)Python 3.8+ (стандартная библиотека, ничего ставить не надо); для прыжков и определения провайдера желательны ping и traceroute
РасширениеChrome и другие на Chromium (Manifest V3), Firefox 91+; режим разработчика
Маяк dnetdГотовый бинарник под вашу архитектуру или любой компилятор C
Сборки не подписаны сертификатом: Windows SmartScreen может предупредить, нажмите «Подробнее → Выполнить в любом случае». Сверяйте SHA-256. Бинарники для Linux и macOS собираются на GitHub Actions (.github/workflows/build.yml) или командой python3 packaging/build_unix.py на самой системе.
