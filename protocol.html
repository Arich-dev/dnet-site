Обмен между узлами

ПортТранспортНазначение
UDP 48555один JSON-пакетМаяк «я здесь»: {"dnet": 1, "id": "…"}. Получатель отвечает по TCP.
TCP 48556одна JSON-строка запроса на соединениеОтвет — строка заголовка и, если есть тело, столько байт, сколько указано в len.

Лимиты: строка запроса и заголовка — до 1 МБ, страница — до 20 МБ. На одно TCP-соединение приходится один запрос.

Операции

ЗапросОтвет
{"op": "hello", "id", "nick", "sup", "port", "v": 1}то же самое про отвечающего; у маяка добавлено "kind": "router". Отправитель регистрируется у получателя.
{"op": "peers"}{"peers": [["10.0.0.5", 48556], …]} — до 20 адресов известных соседей.
{"op": "index"}{"items": [[ключ, адрес, время, размер], …]} — последние сохранённые страницы (не больше 150).
{"op": "get", "key": "…"}{"ok": true, "url", "ctype", "saved", "len": N} и N байт HTML; если страницы нет — {"ok": false}.
{"op": "want", "url": "…"}{"ok": true}; супер-узел ставит адрес в очередь на скачивание из интернета.

Что проверяет получатель

  • В hello: id — 8–64 символа hex, port — целое 1–65535, nick — строка (обрезается до 32 символов), sup — булево.
  • В get: тип text/html, непустое тело, SHA-256 адреса совпадает с запрошенным ключом, адрес не попадает под правила приватности.
  • В index: ключ — 64 символа hex и действительно равен хэшу адреса; приватные адреса отбрасываются.
Подписей и шифрования между узлами нет: узел проверяет формат, но не личность соседа. Подробнее — в разделе «Безопасность».

HTTP API узла

Слушает 127.0.0.1:8765 (параметр api_bind в конфиге меняет адрес). Им пользуются расширение и панель.

ЗапросЧто делает
GET /Панель управления (HTML).
GET /statusJSON: id, ник, число страниц и размер, уровни сети, соседи (адрес, прыжки, тип, супер-узел), найденные подсети, режим сканера.
GET /pagesJSON: свои страницы и те, что есть только у соседей (remote: true).
GET /has?url=…Когда страница сохранена у этого узла (или null). Адрес — в URL-кодировке.
GET /page?url=…Копия страницы: с этого узла или, если нет, у соседей. 404, если нигде не нашлась.
POST /saveСохранить страницу (заголовки X-Url, X-Ctype, тело — HTML). Только с локального адреса и от расширения Chrome.
POST /clearОчистить кэш. Только с локального адреса и со своей панели (проверяется Origin).

Страницы отдаются с заголовком Content-Security-Policy: sandbox, поэтому скрипты в сохранённых копиях не выполняются.

Пример: посмотреть на всё руками

curl -s http://127.0.0.1:8765/status
curl -s http://127.0.0.1:8765/pages
# у кого-то из соседей спросить индекс напрямую:
printf '{"op": "index"}\n' | nc 192.168.1.10 48556
