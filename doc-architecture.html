Узел написан на Python 3.8+ без внешних зависимостей, только стандартная библиотека. Расширение и узел общаются по loopback; наружу узел слушает только 48555/48556.

Как соседи находят друг друга

  1. Маяк. Каждые 15 секунд узел шлёт UDP-пакет {"dnet":1,"id":"…"} на 255.255.255.255 и широковещательный адрес своей /24 (порт 48555).
  2. Получив маяк незнакомого узла, узел отвечает ему TCP-запросом hello.
  3. Синхронизация раз в 20 секунд: у каждого соседа спрашиваются hello (подтвердить, что жив), index (какие страницы есть) и peers (с кем он знаком — до пяти новых адресов проверяются сразу).
  4. Дополнительно: static_peers из конфига, сканер подсетей (probe.py), Bluetooth.
  5. Сосед считается живым, пока не прошёл ttl после последней встречи (300 с для найденных по сети, 120 с — для найденных сканером или вручную).

«Прыжки» считаются по TTL ответа на ping: сколько маршрутизаторов между вами.

Как открывается страница при обрыве

  1. Браузер: ошибка сети (ERR_NAME_NOT_RESOLVED, NS_ERROR_UNKNOWN_HOST и т. п.).
  2. Расширение проверяет GET /page?url=…. Если ответ 200, вкладка переходит на эту копию.
  3. Узел ищет страницу у себя; если нет — спрашивает соседей: сначала того, чей индекс её содержал, потом ближайших, всего до шести. Найденное сохраняет у себя.
  4. Если не нашёл нигде, а включён режим супер-узла (у него или у соседей), запрос запоминается («want»), и супер-узел докачает страницу, когда появится интернет.

Копия открывается в песочнице (Content-Security-Policy: sandbox), скрипты на ней не выполняются.

Протокол между узлами

UDP 48555. Маяк: {"dnet": 1, "id": "<hex 8..64>"}, пакет до 512 байт.

Расширения hello: "kiwix": true (у узла есть Kiwix) и "share": <порт> (раздаёт DNet); старые узлы их игнорируют.

TCP 48556. Один запрос на соединение. Запрос — одна строка JSON, оканчивающаяся \n. Ответ — строка JSON с заголовком; если есть "len": N, дальше идёт ровно N байт тела.

ЗапросОтвет
{"op":"hello","id","nick","sup","port","v":1}то же самое о ответившем узле; у роутера ещё "kind":"router"
{"op":"index"}{"items":[[key,url,saved,size],…]} — до 150 свежих страниц, без запрещённых политикой
{"op":"peers"}{"peers":[[ip,port],…]} — до 20 известных соседей (без Bluetooth)
{"op":"get","key":"<sha256 url>"}{"ok":true,"url","ctype","saved","len":N} + тело, либо {"ok":false}
{"op":"want","url":"…"}{"ok":true}; супер-узел запоминает адрес
{"op":"near"}{"supers":[[ip,port,id,nick]…],"nodes":[[ip,port]…]} — ближние публичные суперноды и узлы (для входа в сеть через интернет, INTERNET.md)
whoami, relay, fwd, relayed, punchNAT, ретрансляция и пробивка: NAT.md
{"op":"hot"}{"items":[[key,url,saved,hits],…]} — до 50 самых частых страниц; по ним соседи делают запасные копии
{"op":"wiki","url":"…"}{"ok":true,"url","ctype","saved","len":N} + HTML статьи из Kiwix, либо {"ok":false}

key — SHA-256 от адреса страницы без #фрагмента. Принимающий узел проверяет всё: формат id, тип содержимого (только text/html), что key действительно соответствует url, что адрес не запрещён политикой, размер (строка до 1 МБ, тело до 20 МБ).

HTTP API узла

Базовый адрес http://127.0.0.1:8765.

ЗапросОписание
GET /Панель
GET /statusJSON: id, nick, pages, bytes, net (уровни), super, scanner, bluetooth, nets, peers
GET /pagesСписок страниц: свои и те, что только у соседей
GET /has?url={"saved": <время или null>}
GET /page?url=Копия страницы (с жёлтой плашкой) или 404
POST /saveСохранить страницу: тело — HTML, заголовки X-Url, X-Ctype. Только от расширения (Origin: chrome-extension://… или moz-extension://…) и только с этого компьютера
POST /clearОчистить кэш. Только с панели узла (Origin = адрес самой панели) и только с этого компьютера

Остальное, что открыто с других компьютеров при api_bind=0.0.0.0, — только чтение.

Маяк роутера

dnetd.c честно отвечает на все запросы протокола, но страниц у него нет: hello (с "kind":"router") и peers — по существу, index — пустым списком, get — {"ok":false}, want — {"ok":true} без последствий, остальное — {"error":"bad op"}. Таблица соседей — в RAM (64 записи, не больше 8 с одного адреса), не больше 40 соединений в секунду. Полноценные узлы не просят у роутеров страницы (kind = router).
