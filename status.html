Известные ограничения

  • Широковещательный адрес считается как для /24. В подсетях другого размера (например /27) UDP-маяк может не дойти; выручают static_peers и маяк на роутере. Расчёт по реальной маске — в планах.
  • Узлы в разных подсетях. Если сеть не пропускает трафик между сегментами (школьный Wi-Fi и проводная сеть, например), узлы друг друга не увидят — проверено на практике.
  • VPN. Если VPN заворачивает в туннель и локальную подсеть, трафик до соседей не дойдёт. Добавь локальные подсети в исключения VPN.
  • «Прыжки» считаются по TTL ответа ping (приблизительно); Windows по умолчанию на ping не отвечает — тогда число прыжков не определяется.
  • Без traceroute не работают автоопределение провайдера и путь до цели; остальное работает.
  • Расширение для Firefox временное (без подписи Mozilla); Chrome требует режима разработчика.
  • Значок в трее есть в Windows и (с pystray) в Linux; в macOS — только окно.
  • Сборки не подписаны сертификатом: SmartScreen и антивирусы могут ругаться.
  • Нет подписей и шифрования — см. «Безопасность».

Планы

  • Проверить dnetd на OpenWrt (WR741N), запустить бинарники на других роутерах.
  • Запустить остальные платы (NanoPi, Banana Pi, BeagleBone).
  • Считать широковещательные адреса по маске подсети.
  • Подписи страниц, проверка подлинности узлов, шифрование канала.
  • Подпись расширения (AMO, Chrome Web Store) и сборок, настраиваемые исключения приватности.

Журнал изменений

  • 0.3 — окно с вкладками и значок в трее с мини-окном, автозапуск без прав администратора (Windows, Linux, macOS), расширение для Firefox и переработанное для Chrome (настраиваемый адрес узла, значки, проверка копии перед подменой), готовые программы: установщик, переносная версия, бинарники Linux и macOS, .pyz; маяк для роутеров под 6 архитектур с install.sh и пакетом OpenWrt; документация.
  • 0.2 — панель узла и окно расширения, фильтр приватных страниц, режим --debug с окном логов, страницы «у соседа» в панели, маяк dnetd для роутеров с логом, автозапуск (systemd и скрипты для роутеров), run.bat и демонстрация на одном компьютере.
  • 0.1 — узел, обнаружение соседей, обмен страницами, расширение Chrome.
