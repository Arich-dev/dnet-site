Маяк для роутеров

Роутер включён всегда и стоит между подсетями, поэтому он лучший помощник в обнаружении. dnetd.c — один файл на C без потоков и динамической памяти в коде: отвечает на запросы, ведёт таблицу в RAM и рассылает маяк. Собранный родным gcc на ARM64 весит около 20 КБ.

  • В таблице 64 записи, не больше 8 с одного адреса; не больше 40 соединений в секунду.
  • Лог dnetd.log лежит рядом с бинарником, не больше 4 КБ (при переполнении начинается заново), сбрасывается при каждом запуске, не чаще 30 строк в минуту — чтобы не изнашивать флеш.
  • Свой путь лога — dnetd -l /tmp/dnetd.log (на OpenWrt корень только для чтения), без лога — dnetd -n.
  • Готовые статические бинарники: mipsel, mips, arm, aarch64, x86, x86_64 (кросс-сборка python router/build.py, нужен только zig).
  • install.sh сам определяет архитектуру и систему; настройки OpenWrt — в /etc/config/dnetd; есть пакет для SDK. Скрипты автозапуска: OpenWrt (procd), Keenetic (Entware), DD-WRT/Tomato, NetBSD, systemd. Подробнее — документация.
