Сборка из исходников

Нужен Python 3.8+ (для окна — с Tk; в Windows он есть по умолчанию). Сам узел собирать не нужно, он запускается как python daemon/main.py. Сборка нужна для готовых программ.

Всё, что собирается

ЧтоКомандаРезультат
Windows: exe, установщик, портативная версияpip install pyinstaller и python packaging/build_windows.pydist/DNet.exe, dnet-cli.exe, DNet-0.3-Setup.exe, DNet-0.3-portable.zip
Linux / macOS: бинарникpip install pyinstaller и python3 packaging/build_unix.pydist/dnet-0.3-<ос>-<арх>.tar.gz

Значкиpython tools/make_icons.pyextension/icons/*.png
Сайтpython site_src/build.pysite/ и архивы в site/downloads/

PyInstaller собирает только под ту систему, на которой запущен. Поэтому в репозитории настроена автосборка на GitHub Actions (.github/workflows/build.yml): Windows, Linux (x64 и arm64), macOS (Intel и Apple Silicon) и роутеры собираются на чистых серверах.

Единственный экземпляр, портативный режим

  • Повторный запуск DNet.exe не создаёт второй узел: он видит, что на порту 8765 уже отвечает DNet, и просто открывает панель.
  • Файл portable.txt рядом с программой переключает хранение данных в ./data. В исходниках, чтобы попробовать, положите его рядом с daemon/ или в корень проекта.

Расширения

extension/ — исходники для Chrome (Manifest V3, фоновый service worker). Код общий для двух браузеров: используется browser.* (Firefox) или chrome.*. Единственное отличие — манифест: extension/manifest.firefox.json (Manifest V2, browser_action, фоновая страница, browser_specific_settings). Скрипт tools/build_extensions.py собирает из них готовую папку extension-firefox/, не правьте её руками: изменения делайте в extension/ и пересобирайте.

Сайт

site_src/pages/*.html — страницы (две первые строки title: и desc:), layout.html — шаблон, static/ — стили и скрипты. python site_src/build.py собирает site/ и считает контрольные суммы всех файлов для скачивания. Если в dist/ лежат готовые exe, установщики и бинарники роутеров, сборщик положит их на страницу «Скачать». Выкладка на VPS: deploy/vps/ (push_site.sh).

Тесты

Автоматических тестов в репозитории нет; для проверки используйте:

python daemon/main.py --version
# два узла на одном компьютере (разные порты и папки):
demo_two_nodes.bat

Для проверки окна и трея запустите python daemon/main.py --gui.
