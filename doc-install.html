Установка

DNet состоит из трёх частей: узел (программа на компьютере), расширение браузера и, по желанию, маяк для роутера. Узел можно поставить без прав администратора.

Все готовые файлы собираются в папку dist/ командами из BUILD.md и лежат на странице «Скачать» сайта.

Windows

Есть три способа. Права администратора не нужны ни в одном.

СпособФайлКогда выбрать
УстановщикDNet-0.3-Setup.exeОбычная установка: ярлыки, автозапуск, пункт в «Установка и удаление программ»
Переносная версияDNet-0.3-portable.zipФлешка, чужой компьютер, ничего не менять в системе
Из исходниковrun.bat (нужен Python 3.8+)Разработка и отладка

Установщик

  1. Запустите DNet-0.3-Setup.exe. Он ставит программу в %LOCALAPPDATA%\Programs\DNet (свою папку можно выбрать кнопкой «Обзор»).
  2. Отметьте, нужны ли ярлык на рабочем столе, автозапуск и запуск сразу после установки.
  3. Значок DNet появится в области уведомлений (трее). Клик по нему открывает мини-окно, двойной клик — главное окно.

Тихая установка для скриптов: DNet-0.3-Setup.exe /S. Тихое удаление: "%LOCALAPPDATA%\Programs\DNet\uninstall.exe" --uninstall /S (добавьте --purge, чтобы стереть и сохранённые страницы).

Переносная версия

Распакуйте DNet-0.3-portable.zip куда угодно и запустите DNet.exe. Пока рядом лежит файл portable.txt, всё (настройки, кэш страниц, значки) хранится в папке data рядом с программой — на компьютере ничего не остаётся. Удалите portable.txt, чтобы вернуться к обычной папке %USERPROFILE%\.dnet.

В архиве есть и dnet-cli.exe — то же самое, но с консольным интерфейсом.

Как работает «без прав администратора»

  • Программа ставится в папку пользователя, а не в Program Files.
  • Автозапуск — запись в HKCU\...\Run (только для вас), а не служба и не задача планировщика.
  • Все порты узла выше 1024, их можно открывать без администратора.
  • Единственное, что может попросить повышения, — брандмауэр Windows: при первом запуске он спросит, разрешить ли сеть. Нажмите «Разрешить» для частной сети. Если отказать, узел будет видеть соседей только по исходящим соединениям (см. TROUBLESHOOTING.md). Правило можно добавить и вручную, это единственное действие, для которого нужен администратор:
netsh advfirewall firewall add rule name="DNet" dir=in action=allow protocol=UDP localport=48555
netsh advfirewall firewall add rule name="DNet TCP" dir=in action=allow protocol=TCP localport=48556
  • Если нужен узел для всех пользователей и до входа в систему, включите режим службы: DNet.exe --autostart on --system из консоли администратора (создаёт задачу планировщика от имени SYSTEM, которая запускается при загрузке).

Windows SmartScreen и антивирус

Сборки не подписаны сертификатом, поэтому SmartScreen может написать «Windows защитила ваш компьютер»: нажмите «Подробнее → Выполнить в любом случае». Одиночные exe, собранные PyInstaller, иногда ложно срабатывают у антивирусов. Контрольные суммы SHA-256 лежат на странице «Скачать»; кому важно, может собрать всё сам (python packaging/build_windows.py) или запускать из исходников.

Linux

Бинарник (dnet-0.3-linux-x64.tar.gz или -arm64):

tar xzf dnet-0.3-linux-x64.tar.gz
cd dnet-0.3-linux-x64
sh install.sh        # ставит в ~/.local/opt/dnet, без root
dnet --gui           # окно; dnet --tray — в трей; dnet — консоль

Для значка в трее нужен pystray и pillow (pip install pystray pillow) в системе, где запускаете из исходников; в бинарнике окно сворачивается в панель задач.

Чистый Python (любая система, любой процессор, нужен Python 3.8+): скачайте dnet-0.3.pyz и запустите python3 dnet-0.3.pyz. Для окна нужен пакет Tk (sudo apt install python3-tk).

Автозапуск без root:

dnet --autostart on        # systemd --user, а если его нет — ~/.config/autostart
dnet --autostart status
dnet --autostart off

Чтобы пользовательская служба работала и без входа в систему: loginctl enable-linger $USER. Для сервера или платы (на весь компьютер): sudo dnet --autostart on --system — ставит /etc/systemd/system/dnet.service. Готовый шаблон лежит в deploy/dnet.service.

Порты, которые надо разрешить в файрволе: UDP 48555 и TCP 48556 (sudo ufw allow 48555/udp && sudo ufw allow 48556/tcp).

macOS

Скачайте dnet-0.3-macos-arm64.tar.gz (Apple Silicon) или -x64.tar.gz (Intel), распакуйте и выполните sh install.sh. Установщик кладёт программу в ~/Applications/DNet и снимает карантинный флаг. Программа не подписана Apple: если система ругается, выполните xattr -dr com.apple.quarantine ~/Applications/DNet.

Значок в строке меню в macOS не поддерживается (Tk и системный трей конфликтуют в одном потоке): работают окно и консольный интерфейс. Автозапуск — LaunchAgent: dnet --autostart on.

Без бинарника: python3 dnet-0.3.pyz --gui (Python 3.8+ с Tk).

Расширение браузера

Расширение сохраняет открытые страницы на узел и подменяет ошибки сети копией. Узел должен быть запущен.

Chrome, Edge, Brave, Opera, Яндекс Браузер (одна и та же папка):

  1. Откройте chrome://extensions (в Edge — edge://extensions), включите «Режим разработчика».
  2. «Загрузить распакованное расширение» → папка extension (в установщике и портативной версии лежит рядом с программой).

Firefox:

  1. Откройте about:debugging#/runtime/this-firefox → «Загрузить временное дополнение…» → файл manifest.json из папки extension-firefox. Так расширение работает до закрытия браузера.
  2. Постоянная установка: Firefox Developer Edition или Nightly с xpinstall.signatures.required = false в about:config, затем установите файл dnet-firefox.xpi. Для обычного Firefox нужна подпись Mozilla (AMO), её у проекта пока нет.

В окне расширения есть переключатель «Включено/Выключено» и поле «Адрес узла» — на случай, если вы поменяли порт (DNET_API_PORT).
