Быстрая установка

1. Скачай DNet-0.5-Setup.exe и запусти (права администратора не нужны)
   или DNet-0.5-portable.zip: распакуй куда угодно и запусти DNet.exe
2. Значок DNet появится в трее: клик — мини-окно, двойной клик — окно
3. Расширение: Chrome — chrome://extensions → режим разработчика →
   «Загрузить распакованное» → папка extension (Firefox: см. ниже)
4. Открой любую страницу, затем окно DNet → «Файлы»

Установщик ставит программу в %LOCALAPPDATA%\Programs\DNet и включает автозапуск для текущего пользователя. Тихая установка: DNet-0.5-Setup.exe /S. Из исходников (нужен Python 3.8+): run_gui.bat или run.bat (консоль).

tar xzf dnet-0.5-linux-x64.tar.gz && cd dnet-0.5-linux-x64
sh install.sh            # в ~/.local/opt/dnet, без root
dnet --gui               # окно;  dnet --tray — в трей;  dnet — консоль
dnet --autostart on      # автозапуск (systemd --user)

# без бинарника, любая система с Python 3.8+:
python3 dnet-0.5.pyz --no-ui

Для платы или сервера на весь компьютер: sudo dnet --autostart on --system. Порты UDP 48555 и TCP 48556 разреши в файрволе.

tar xzf dnet-0.5-macos-arm64.tar.gz && cd dnet-0.5-macos-arm64
sh install.sh
~/Applications/DNet/dnet --gui

# собрать самому на своём маке:  python3 packaging/build_unix.py

Программа не подписана Apple — установщик снимает карантинный флаг. Значка в строке меню на macOS нет, работают окно и консоль.

scp -r router root@192.168.1.1:/tmp/dnet     # папка из архива маяка с бинарниками dnetd-*
ssh root@192.168.1.1 'sh /tmp/dnet/install.sh'

# сборка под свой роутер (нужен только zig):
pip install ziglang && python router/build.py

install.sh сам определяет архитектуру (MIPS, ARM, AArch64, x86) и систему (OpenWrt, Keenetic/Entware, DD-WRT, systemd). Подробнее — документация по роутерам.

Порты UDP 48555 и TCP 48556 разреши в файрволе. На Windows при первом запуске брандмауэр спросит доступ — разреши для частной сети.

Расширение для браузера

БраузерКак поставить
Chrome, Edge, Brave, Opera, Яндексchrome://extensions → режим разработчика → «Загрузить распакованное» → папка extension (есть в установщике, портативной версии и в dnet-chrome.zip)
Firefoxabout:debugging#/runtime/this-firefox → «Загрузить временное дополнение» → manifest.json из папки extension-firefox. Постоянно — в Developer Edition / Nightly (файл .xpi, xpinstall.signatures.required=false)
Обычный Firefox принимает только расширения, подписанные Mozilla; подписи у проекта пока нет. Расширение для Firefox написано, но на самом браузере пока не проверялось — см. «Проверено».

Без прав администратора

  • Установщик ставит в профиль пользователя; автозапуск — ключ Run в HKCU, а не служба.
  • Переносная версия не трогает систему вообще: положи portable.txt рядом с DNet.exe — данные лягут в папку data.
  • Linux: systemd --user и установка в ~/.local. macOS: LaunchAgent и ~/Applications.
  • Всем портам больше 1024. Администратор нужен только по желанию: правило брандмауэра, служба на весь компьютер (--autostart on --system).

Конфиг

Файл ~/.dnet/config.json (на Windows — C:\Users\имя\.dnet) создаётся при первом запуске. Рядом лежит кэш pages.db. Папку можно сменить переменной DNET_HOME.

КлючПо умолчаниюСмысл
nickимя компьютераИмя в списках соседей
ttl_days14Сколько хранить страницы
max_mb200Лимит кэша
api_bind127.0.0.1Адрес API и панели. 0.0.0.0 — смотреть панель с других машин; запись и очистка остаются доступны только самому узлу
targetsya.ru (страна), 1.1.1.1 (мир)Хосты для проверки уровней. provider определяется сам, city пусто = пропуск
static_peers[]Адреса соседей вне вашей подсети: "10.0.5.26" или "10.0.5.26:48556"
probe.enabled / probe.max_hostsда / 254Сканер подсетей и бюджет адресов в чужих подсетях
super.enabled / max_mb / batchнет / 2000 / 20Режим супер-узла, его лимит кэша и число страниц за цикл
bluetooth.enabled / channel / peersнет / 4 / []Bluetooth RFCOMM; peers — MAC-адреса соседей. Автопоиск устройств работает, если установлен PyBluez

Переменные окружения

Нужны для тестов нескольких узлов на одном компьютере (так работает demo_two_nodes.bat) и для запуска без правки конфига.

ПеременнаяЧто меняет
DNET_HOMEПапка конфига и кэша
DNET_UDP_PORT, DNET_TCP_PORT, DNET_API_PORTПорты маяка, обмена и панели
DNET_STATIC_PEERSАдреса соседей через запятую (добавляются к конфигу)
DNET_NO_PROBE=1Выключить сканер подсетей

Два узла на одном компьютере

Нет второго компьютера или сеть не пускает? demo_two_nodes.bat запускает два настоящих узла. Узел A (панель :8765) работает с расширением, узел B (панель :8766) изображает второй компьютер. Страницы, открытые в Chrome, появляются в панели B с пометкой «у соседа» примерно через 20 секунд, по клику открываются с A по тому же протоколу, что и между машинами.
